# GARAGE AR — 最小版

QR・会員登録・管理画面なしで、好きな床や机に愛車を呼び出すWebXR ARアプリ。

## 使い方
1. Android端末のChromeでHTTPSの公開URLを開き、「ARを開始」。
2. 床または机を映し、検出リングが現れたら「ここに呼び出す」をタップ。
3. ハッチが開き、愛車が地下からせり上がる演出を表示。
4. 周囲を歩いて鑑賞。「運転する」で4方向ボタンが出現。押し続けて前進・バック・左右操作。
5. 「再召喚」で別の位置に置き直せる。

「3Dで試す」はAR非対応環境向けの非ARプレビュー。ARカメラ機能は含まれない。

## 技術
- Three.js / WebXR `immersive-ar`, required features `hit-test`, `dom-overlay`。
- 元のGLBのジオメトリ・UV・マテリアル設定を維持。配信用にPBRテクスチャ画像のみJPEG再圧縮。
- 0.62m程度の模型サイズ（AR中は現実のものに当たらない低速ラジコン操作）。
- WebXRのヒットテストで水平面に配置。視聴者は実際に歩いて回り込む。
- ブラウザ単体で動作。HTTPS配信が必要。3DライブラリはCDNから初回ダウンロード。

## 制約
- ChromeおよびGoogle Play開発者サービス(AR)など、WebXR ARCoreをサポートする環境が必要。
- 車体は単一メッシュなのでドア・タイヤの個別アニメーションは未実装。
- 地下からの上昇はCGの切り抜き演出であり、現実の床に穴を空けたり、実物体による隠蔽を行うものではない。
- 自車の運転は仮想座標移動で、実物の壁や床上の物体との衝突判定は行わない。
- 実機WebXR AR / DOM Overlayの最終検証は対応スマホで行う必要がある。

## 最低限の検証
`node --test motion.test.mjs` で前進、左右、バック、停止を確認。

元のGLBファイルは変更しない。
