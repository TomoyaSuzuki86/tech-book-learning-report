# GARAGE PARK v2 / 愛車の駐車ゲーム

Tripo AIの愛車GLBを使ったブラウザ駐車ゲーム（Render用静的サイト）。

## 実装
- 外観追従、車内、**車中心の俯瞰オービット**。俯瞰でドラッグ→車の周囲を回転、ピンチ→ズーム。カメラの独立した平行移動・「車に戻る」ボタンは無し。
- +Z向きを前進としたステアリング。右を押せば前進で右旋回。後退時の旋回方向は自然に反転。
- 車体中心を基準とした簡易自転車モデルの操舵。速度0で旋回しない。
- 2.68m幅、5.22m長の駐車枠、両側の実車モデル、ポール、背後の壁。
- 見える障害物と一致するOBB判定、細分化移動、接触時は停止／逃げ動作が可能。開始時に障害物と接触しない。
- 駐車位置・車体角度・停止を考慮するクリア判定、3コース、再挑戦。
- 車内は元データに内装が無いため、簡易ダッシュボードで表現。ルームミラー・左右ミラーは別視点の3D描画。車内モデルは実車の内装を忠実再現したものではありません。
- Three.jsのGLTFLoaderを使い、車体ジオメトリ、ベースカラー・法線・メタル/粗さマップを読み込む。別の車モデルにすり替えません。

## 操作
- 前進／バック／ブレーキ／左／右：押しっぱなし（スマホ同時押し可能）
- 俯瞰：キャンバス上でドラッグすると車を中心に回転。ピンチ／ホイールで拡大縮小
- キーボード：W/A/S/D、方向キー、Spaceブレーキ、1/2/3視点、Rリセット

## 配置
このフォルダ一式をHTTPS上に配置。`index.html` を開く。Three.jsは外部CDN `cdn.jsdelivr.net` から読込むため、初回アクセス時に通信環境が必要。

## 品質確認と制限
- `node --test physics.test.mjs`：操舵、旋回中心、前進・後退、接触判定、駐車判定のテスト。
- 車の元ジオメトリは 5,866 三角形（7,878頂点）で保持。テクスチャは配信用に縮小／圧縮。
- 車輪やドアは元のモデルでは単一メッシュで、個別アニメーションなし。
- ブラウザ上のWebGL描画、スマホでの触感、走行体験は実機最終確認が必要。単体テストはそれを代替しません。
- 車内表示とミラーは試作表現で、リアリズムは今後の改善対象。

元のFBX／GLBは変更していません。
